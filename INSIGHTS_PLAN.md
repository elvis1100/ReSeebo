# Store insights plan

## Scope
Keep the store box's View insights pill styled like the former markup badge. Open a locally generated PDF report with compact price-change and supplier-comparison tables. Remove purchase summary and the old sideways-scrolling table UI. Keep markup editing in Settings.

## Data rules
- Read complete product comparison histories through the local adapter rather than the dashboard's limited recent-receipt list.
- Compare the exact brand, variant, and size. All prices and differences are cost per piece.
- Default price changes to the last 30 local calendar days including today; also offer this month and all history. Exclude future purchases from period summaries.
- Use existing deltas against the previous purchase at the same supplier; preserve purchase dates and ordering notes.
- Supplier comparisons always use latest saved prices across all history. Show dates, retain tied lowest suppliers, and label a sole supplier as Only recorded supplier. Do not substitute lowest historical prices.
- Recorded prices are not current offers. Do not claim sales or actual business profit.

## Implementation
1. Generate an A4 PDF snapshot from local data with the already-bundled Inter font. No downloaded fonts or cloud generation.
2. Show price-change rows with product identity, supplier/date, previous/latest amounts, and signed peso/percentage changes.
3. Show a four-column supplier table per product: supplier, purchase date, cost per piece, and difference from the lowest recorded supplier. Highlight lowest rows and sort by price.
4. Include fine grid lines, alternating rows, store name, generation time, period, repeated column headers, and page numbering. Keep empty-table headers and explain sparse history.
5. Display the PDF with zoom, share, and print actions. Regenerate on refresh or period change, caching the generated bytes for preview requests. Keep retry and back navigation.

## Result and verification
Implemented the report generator and replaced the Insights screen body with a PDF viewer. Removed the superseded native table widgets. The existing dashboard button now opens the report. No database/schema changes.

Six focused insights tests passed: first-purchase visibility, dashboard PDF navigation, empty-report generation, multi-page generation, calendar periods/deduplication, supplier ties, and load retry. Rendered the sample report with pdftoppm and visually inspected its first page: table borders, long supplier wrapping, product identities, peso glyphs, and lowest-price highlights are legible. Text extraction also retained dates and exact amounts. A repeated-data stress report generated 33 pages.

Static analysis is part of the final combined checks. PDF generation and navigation have local proof; native PDF rasterization, sharing/printing, first-launch airplane-mode use, and persistence after restart still require device verification. Android/iOS rendering uses native plugin facilities; web preview's default pdf.js fetch is outside the offline mobile verification claim.
